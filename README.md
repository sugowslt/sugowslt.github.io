# 신재현 백엔드 개발자 이력서

Gatsby 기반 GitHub Pages 이력서입니다.

- 공개 주소: https://sugowslt.github.io/resume/

## 로컬 실행

```powershell
npm install
npm run develop
```

기본 주소는 `http://localhost:8000`입니다.

## 빌드

```powershell
npm run build
npm run serve
```

## 공개 전 확인

- 공개 페이지에는 휴대전화 번호를 넣지 않았습니다.
- 수상 연도와 수상작 세부 내용은 공식 자료 확인 후 추가합니다.
- 현재 대표 프로젝트는 검증이 완료된 `kotlin-payment-core-api`만 포함합니다.
- 다른 프로젝트는 저장소 상태와 검증 결과를 확인한 뒤 추가합니다.
