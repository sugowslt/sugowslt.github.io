# 신재현 백엔드 개발자 이력서

Gatsby 기반 GitHub Pages 이력서입니다.

- 공개 주소: https://sugowslt.github.io/resume/

## 로컬 실행

```powershell
npm install
npm run develop
```

기본 주소는 `http://localhost:8000`입니다.

## 빌드

```powershell
npm run build
npm run serve
```

## 공개 전 확인

- 공개 페이지에는 휴대전화 번호를 넣지 않았습니다.
- 수상 연도와 수상작 세부 내용은 공식 자료 확인 후 추가합니다.
- 대표 프로젝트는 결제 API, 비동기 정산, 관측성 실습을 하나의 Kotlin 백엔드 시리즈로 묶어 소개합니다.
- 각 프로젝트 설명은 공개 저장소에서 확인 가능한 구현과 실제 테스트 결과만 사용합니다.
